# 累计作品时间基线与新增统计

本轮用户明确替代上一快照ID差集统计。适用于全部博主，不要求本地作品列表覆盖作者的全部历史。

## 时间与数量

- M：此前已采集作品中最大的有效发布时间，按作品ID累计去重、按发布时间排序，不按置顶或页面顺序取第一条。已失效仍保留原发布时间，因此M不因删除或隐藏倒退。
- X：本次采集完成时间。
- 本次读取新作品数：公开作品中发布时间满足 **M < 发布时间 ≤ X** 的去重ID数。M处是开区间，避免重复计算上次最新作品。新近发布后置顶仍按其真实时间判断，旧作品置顶或重新出现不算新发布。
- Y：本次主页前端“作品”数；净变化为本次Y减上一次观察到的Y。净变化不等同新发布数量，允许正、零、负。
- 新发现但发布时间≤M的记录归为历史补充；已失效作品重新出现，恢复其可见状态，单独记录恢复数量，不算新发布。

时间基线来自累计已采集历史，连续性核验仍保留尚未解决异常的原锚点，避免仅因为重复采集见到了新锚点就误解除缺口。旧异常展示的新增数通过原采集事件前的时间基线重新计算，原始回执不改写。

## 累计记录与失效

从原始采集快照和原生检查页按观察时间重建时间线，新增两个派生表 `creator_work_timeline_states`、`creator_work_timeline_events`。每条作品保留ID、原发布时间、首次/最近读取时间、置顶和active/invalid状态。原快照、作品及用户批注不删除。

本次完整公开列表与主页总数一致时，可核对全部已知作品。部分列表也适用时间线与失效规则：游标连续、普通作品按发布时间倒序、无读取错误或未知可见性时，可以核对已连续覆盖的时间区间。区间最旧时间点可能还有未翻到的同秒作品，边界同秒记录不推断缺失；更早未读取区域保留原状态。读取中断、顺序冲突、未知可见性、全部置顶等无法证明覆盖时，不凭缺失标记失效。

“已失效”表示在已核对范围内未出现，不能仅靠此标签区分删除、隐藏或平台状态变化。恢复公开后保留历史并恢复状态。

## 展示和间隔

博主卡片显示本次新作品数、主页总数前后变化、M与X、补充历史/失效/恢复数量。按需展开“按时间查看累计作品记录”，从旧到新显示原发布时间和“已失效”标签。

平均发布间隔继续用累计有效发布时间去重排序后计算；新完整列表或作品失效不会剔除旧发布时间，因此用户例子中10月14日删除两条不改变间隔。待核验的异常观测仍不冒充已经通过的正常资料；成功核验后按累计历史更新。

连接器读取范围同时满足本周边界与M覆盖，不在本周边界提前截断跨周新增作品。保留原分页、安全停止、单轮范围与等待策略；本次范围未完整覆盖时显示“本次已读结果”。
