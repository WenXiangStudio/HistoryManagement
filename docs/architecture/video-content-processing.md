## 使用流程

1. 在“视频信息”选择博主（可多选）和起止发布日期，点击“查找日期范围内作品”。日期按北京时间解释，起止日均包含。
2. 查找只保存基础资料和清单，不自动下载、转写或调用模型。可以查看历史日期、筛选当前保存资料；不限定最新一条。
3. 勾选需要处理的作品，点击“本地提取选中”，或处理当前筛选结果全部。程序连续执行媒体读取、语音转写、全时间轴抽帧和OCR，每条结果独立保存。
4. 点击作品，展开口播全文或画面证据，标记“感兴趣 / 不感兴趣”，也可清除标记。标记不改变作者权重，不表示已观看，不删除作品。
5. 在设置配置文本服务 Base URL、API Key、模型和接口协议（Responses / Chat Completions）；需要视觉补充时另配视觉服务。回到视频页，勾选作品，选择“云端补充摘要”或“云端补充画面”。当前用户文本配置已选择Responses；单价是可选信息，用户已明确不需要追问。

更换厂商时，先在“云端兼容 API”顶部点击“新建方案”，再填写名称及服务参数；原模型和密钥保留，可从“云端方案”下拉框切回。新方案为空，不继承旧密钥；复制方案后可独立修改。有草稿时先选择保存、放弃或继续编辑；正在处理内容时暂不能切换。方案管理只保存与选择配置，不会自动验证新模型的模态支持，也没有新增音频或视频协议适配。

文本协议选择同时用于视频摘要及共用文本设置的旧作品/评论分析入口，不开启旧能力门。Responses发送`/responses`，实际任务及结构要求置于developer输入，材料置于user输入，使用`store:false`和流式输出；从`response.completed`提取最终内容和用量，拒绝中断、失败与拒答，仍检查摘要字段和证据引用。选择Responses后不会暗中退回Chat Completions。旧配置未指定协议时保持Chat Completions，本地llama.cpp及独立视觉路径保持原协议。

**本地摘要质量门保持关闭。** Qwen3-4B-Instruct-2507 与 Qwen3.5-4B 的真实样本出现主语归属错误、把含糊/玩笑扩写为论断等问题，不能把格式与引用ID正确当作内容忠实。当前“本地提取完成”会显示“待补充摘要”，不生成或展示这些被拒绝的摘要。2026-10-11用户在APP配置文本服务，gpt-6.1-sol的流式JSON连接及APP同一摘要函数已通过合成材料真实调用；真实视频内容质量、视觉服务和实际费用尚未验收。

云端摘要完成后展示主题、概览、主要观点与对应原文时间。画面补充最多发送12张均匀选取的静态帧，不能证明完整动作、音乐或表演体验。原文、画面、模型输出分别保留。

## 实现与边界

- 日常库继续使用 following-directory.sqlite。快照以 snapshot_id 唯一，run_id允许多个作品；旧快照原样迁移，旧run_id成为原snapshot_id，首次收录时间不变。旧signal-desk.sqlite作品/收件箱和R8能力门未接入。
- 新增 video_content_interest、video_content_batches、video_content_stages、video_content_settings。阶段版本追加保存，失败不覆盖此前成功摘要；个人标记独立保存。
- 查找沿现有浏览器身份和响应监听，逐页归属验证；非公开视频与非普通视频不作为本入口可处理作品。日期范围完整性按原生分页和非置顶作品时间顺序判断，未知可见性或乱序不能提前宣称完整。
- 每作者每次最多20页或90秒；部分完成保存游标，可继续。元数据查找检查点独立于活跃度/作品总数检查。账号、拒绝、验证码和断线异常停止；已有成果保留。
- 已知历史作品首屏缺失时，在首屏结果成功且账号/归属已核验之后，允许一次目标详情GET。最多一次首屏补GET加一次详情GET；不能把拒绝或异常JSON当缺失补发。这个范围仅用于新媒体任务，原单视频基础信息入口约束保留。
- 媒体URL仅作瞬时执行数据，白名单CDN、大小限制、重定向校验、SHA256与时长校验；持久证据不保存签名URL、Cookie或API Key。
- 本地worker通过NDJSON接收阶段命令，模型仅从已安装目录加载。CPU重计算单任务；切换阶段按需复用模型。Windows取消会终止所启动的进程树，重启将未完成任务标为中断。
- 转写/画面/摘要按阶段缓存，模型、输入和提示词变化使对应结果失效。更新指标、浏览、兴趣标记不触发重新分析。临时媒体默认20GB，超72小时的非活跃媒体可清理；转写、OCR、摘要与引用帧保留。
- 记录服务处理时间、每阶段时间和页面渲染确认时间。只有取得渲染确认才能称为“开始至内容可用”；失败、取消、用户切页/筛选造成的等待不能用阶段时间替代。

## 本机运行环境
