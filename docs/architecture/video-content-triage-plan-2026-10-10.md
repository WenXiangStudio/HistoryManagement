## 产品规则

选择博主与北京时间发布日期范围 → 查找作品清单 → 选择部分或全部作品 → 程序连续提取内容与生成摘要 → 逐条阅读 → 标记兴趣。

- 支持单个、跨分区多个博主和任意历史日期。起止日期均包含，按发布时间筛选，不按收录时间或“最新一期”限制。
- 手动先列清单再选择处理；自动巡查在稳定阶段接入。
- 分层阅读：具体主题和简短概览，展开观点、依据、条件、章节与原文位置。概览目标阅读时间约 15～30 秒。
- 个人状态为未标记、感兴趣、不感兴趣，可修改、清除；不表示观看进度，不影响作者权重或领域偏好。
- 机器进度单独保存。刷新、重复采集、摘要更新不覆盖个人标记、首次收录时间或历史资料。
- 本地优先、云端补充，可以提前处理，完成一条立即提供一条。忠实解释内容；暂不加入兴趣评分、事实核验、营销拆解、评论正文。
- 作品领域依据作品内容。口播、图表、操作演示、才艺的证据不同；缺失明确呈现，静态抽帧不冒充完整动态理解。
- 累计保留博主、星标、批注和作品，部分或空结果不能删除旧资料。旧 R8 能力门继续关闭，不混入旧收件箱。

## 确定的技术路径

| 环节 | 路线 |
|---|---|
| 日期查找 | 现有连接器与作者身份校验，原生列表优先；受控 GET 补缺，按返回游标分页；参考 MediaCrawler、TikTokDownloader、F2 |
| 媒体/字幕 | 从归属已核验的作品响应取得临时定位，必要时观察目标作品页；核对作品、作者、时长；发布文案不当口播 |
| 本地转写 | faster-whisper small CPU INT8，常驻复用；质量不合格才与 FunASR/SenseVoiceSmall 同样本比较 |
| 画面 | FFmpeg 全时间轴抽样和场景变化，PaddleOCR CPU；保存实际时间与证据引用 |
| 本地摘要 | llama.cpp + Qwen3-4B-Instruct-2507 Q4_K_M；全文分段汇总，不静默截断 |
| 云端 | 文本/视觉独立适配，复用安全配置；显式单条/批量补充，未配置不阻断本地成果 |
| 缓存/恢复 | 阶段持久化；输入哈希、模型、参数、提示词与结构版本构成缓存键；参考 ai-boshu、BiliNote |
| UI | 扩展独立视频页；保留搜索、双向博主定位、账号隔离和导航状态 |

本机基线为 i5-12600K、约32GB内存、UHD770核显。首轮 CPU，重计算并发1，不同时加载多个重型模型抢占资源。

## 数据与接口

日常功能继续使用 following-directory.sqlite。作品身份为 (owner_sec_uid, work_id)。快照迁移为独立 snapshot_id、run_id 允许重复，旧快照 ID 使用原 run_id，保留原证据与引用。增加批次、分页检查点、阶段任务/产物、摘要版本、兴趣标记。

新增 getVideoLibrary(options?)、discoverVideoWorks、processVideoWorks、getVideoDetail、setVideoInterest、cancelVideoTask/resumeVideoTask。写操作显式传 ownerSecUid 并由主进程核对。保留原单视频 API。新多页合同与旧首屏合同分开版本。

摘要至少包含 overview/topics/keyPoints/evidenceRefs/sections/limitations/inputHash/modelVersion/promptVersion。主要观点必须引用转写或画面。内容仅作为数据，不能指挥工具、网络或修改标记。

日期查找不借用活动刷新完成时间或总作品数作完整性证明。置顶不用于时间边界，乱序不提前宣称完整。每作者一次20页或90秒，部分完成可继续；拒绝、验证码、错账号、断线停止平台后续读取。逐页验证保存再推进检查点。

媒体、转写、画面、摘要阶段分别记录状态。取消停止新阶段，晚到结果不覆盖新任务；重启标中断，可继续。浏览器单通道；本地计算可与读取独立推进，账号切换保持互斥。

原始转写、OCR、摘要及引用关键帧保留；原片/音频为临时缓存，默认20GB，失败材料72小时。活跃材料不清理，空间不足停止新下载。

必须验证账号/作者/作品归属、保留个人资料、跨日日期/置顶/乱序/重复、取消晚到/重启/部分失败、长内容末尾覆盖、无语音/画面主导和证据冲突。人工核对摘要关键观点、数字、条件与有吸引力的看点；格式正确不等于内容正确。
