# 关注清单与博主动态：当前实现

当前关注连接器为 0.7.9。主要模块是 `following-plan-runner.js`、`FollowingPlanStore`、`creator-activity-runner.js`、`CreatorActivityService` 和共享字段合同。

## 独立动作与数据保留

关注清单同步完整分页读取基础资料，逐页保存。缺失基础字段形成按账号隔离的本地待办，每批最多 20 位。作品总数/本周动态使用独立刷新动作，支持单作者、所选多作者、全部及继续剩余。

资料按账号累计，博主按主页 secUid 去重；保留原记录 ID、星标、批注、历史快照和失败记录。部分列表、空结果或本轮未出现不删除已有博主。后端验证所选 ID 都属于当前账号，禁止静默接受部分无效范围。

## 字段与来源

- 主页作品数：读取作者页可见且稳定的“作品”计数，独立于列表时间统计保存。
- 本周动态：首位作者页核验当前账号；可信的新原生账号响应可复用，未观察到时允许一次主动核验。账号来源或身份拒绝时停止。
- 作品列表：在对应作者同源页面明确 GET 第一页与所需后续页，使用 v7 来源证明；不得把执行尝试计数当作成功 HTTP 请求数。
- 后端复核作者 UID/secUid、原生作品 ID、公开状态、去重、游标连续性、置顶与普通作品时间顺序、日期范围覆盖。
- 本周为北京时间周一至下周一不含末端。“最近更新”仅指本周最近发布；零条为 null，失败或覆盖不完整为未知/partial。

资料按今日、本周非今日、暂无更新三个互斥区域展示。日历边界自动更新展示口径；新发布数据仍需刷新取得。

## 失败捕获

首次错误同步复制网络、浏览器命令、尝试记录和时间，再执行异步存储或截图。停止心跳和后续业务工作，保留故障 tab。

扩展 `signalDeskLatestFailure` 缓存与 APP `creator_activity_diagnostics` 分别尝试持久化，允许 frozen → complete，拒绝改写首次证据或覆盖完整记录。DOM/截图失败时使用独立 tabs 检查；目标页仍匹配才尝试 scripting 读取。仅当明确未连接且没有其他调试器时，诊断可重新附加一次截取截图，不导航、刷新或重发业务请求。

错误与事件有界并按白名单保存，不保存 Cookie、headers、完整 URL/query、表达式或异常原文。Chrome 的“目标已导航或关闭”保留为含糊类别，页面是否存在由独立标签检查补充。

## 验收与性能

性能以一次点击到资料及头像可用为主要指标，列表读取与保存阶段单列。多作者每位可用时间是同一次点击后的累计值。网络观察存在窗口盲区，明确响应数量不等于浏览器总流量。

日常 0.7.9 完成一次点击三位和八位新样本验收，均一次成功。真实 Chrome 本地故障注入覆盖调试断开、导航中断、APP 诊断提交拒绝。没有因此确定历史平台失败的根因，也没有证明长期成功率。

原始捕获和数据库备份留在本机 `local-data/`；可提交的审阅证据在 `docs/evidence/`。正式作品详情、评论和 R8 业务能力是独立范围，当前保持关闭。
