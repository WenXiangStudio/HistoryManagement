# 硅基流动模型自由增删：APP 0.1.48

用户要求设置中的硅基流动配置不再固定三个位置，改为自行添加和删除模型。

## 使用与保存

- 设置 → 硅基流动 · 模型接入 → “新增模型”。模型 ID 可立即填写，也可先保存空模型；各模型独立配置图片输入。
- 每张模型卡片有“删除”。移除已保存模型后显示待保存数量，可点“撤销删除”恢复；统一点击“保存硅基流动配置”才生效。
- 原模型身份、配置和凭据按持久编号保留，删除中间项不会将后续模型的身份、Key 或图片输入设置向前错配。新增模型数量不受原三位或普通方案的 30 套限制。
- 同组共用加密 Key，新模型继承已有硅基流动 Key；留空不更换。删除全部模型仍保留组 Key，再次添加无需重填。
- 删除当前生效模型时，保存前显示自动切换提示；保存时优先切到编号最小的已填写且有 Key 的剩余硅基流动模型，否则恢复已有普通云端方案。方案选择与生效设置在同一事务内提交。
- 保存配置本身不调用模型。旧客户端按位置更新的请求继续兼容，遗漏的既有模型不会被当成删除；删除必须显式给出编号。配置过期、重复编号、未知删除及交叉操作会拒绝并保留当前记录。
