## 两次阻断与真实修正

首次在作者发现阶段阻断：普通 `innerText` 漏掉“🇨🇳挪威老王🇳🇴”昵称中的图片形式国旗，得到“挪威老王”，与其真实头像 alt 不一致。真实卡片 HTML 已留存。

改为保留图片 alt 的 DOM 文本读取后，第二次发现昵称链接选择会误选头像链接，因其图片 alt 被作为文本。随后明确排除包含“头像”图片的链接，只从同卡片的昵称主页链接读取昵称。第三次成功取得全部二十位。两次失败成功人数均为 0，没有写入任何作者记录。

未跳过该博主、未去除国旗以放宽匹配，也未放宽主页/头像归属要求。修正已补入真实采集脚本，离线集成回归使用实际采集代码验证二十位排除、emoji 昵称、头像链接隔离及不匹配阻断；两项通过。既有计时五项也通过，共七项。
