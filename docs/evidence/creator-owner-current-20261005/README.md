## 最终来源规则与请求成本

0.7.4要求账号请求loader/frame等于最初Page.navigate返回标识，上一轮每日英语记录了loader不同但frame/HTTP/JSON/双ID正确。0.7.5在首位作者导航前启用Page事件，用Page.frameNavigated确认已提交主文档；同一作者主页、同一主frame后续提交新的loader时更新当前来源。账号请求需要匹配当前已提交loader/frame、目标主页document分类、无子会话，端点/GET/HTTP200/JSON/双ID仍核对。

Page.navigate返回值和Network的Document请求不等于提交事件；缺少提交、新主文档正在请求但尚未提交、当前网页跳到其他作者/来源、主frame被移除、子frame/子会话及旧loader账号响应均拒绝。无原生账号请求时，确认当前主页提交且无待提交导航后才允许一次主动self GET。已观察的账号HTTP/JSON/身份/来源失败不触发替代GET；多条响应不能遮盖任一已观察错误。等账号响应体期间每次重新检查当前来源，有界诊断数组满后仍更新实时来源。没有跨run/tab缓存或自动重试。

原生证明提交后端时，生产run还要求当前主页已提交、frame与导航相同、账号请求与当前loader/frame相同、HTTP/JSON/双ID均通过；来源诊断本身不是账号证明，账号核验之前仍拒绝作者入库。原始CDP标识、URL/query/header/Cookie和完整账号JSON不持久化，只保存关系及阶段。诊断新增字段可选，旧run和旧诊断不改写。
