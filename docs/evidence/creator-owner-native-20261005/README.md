# 本轮原生账号响应复用验证（2026-10-05）

用户授权继续复用本轮主页原生账号信息，减少程序重复账号GET。已交付关注扩展0.7.3与原桌面入口。第一位作者主页同时用于账号核验、用户指定的前端作品总数和原生作品列表，不加载专用账号页、不重复导航。

## 来源与失败边界

创建本轮后台空白标签后，导航前监听self与作品列表。账号仅接纳该标签、本次导航新发出的GET、精确端点、HTTP200与可解析JSON；返回uid/sec_uid必须匹配已绑定账号，导航loader/frame存在时再次绑定。旧页面、旧run或跨标签响应不作账号证明。

未观察到self请求时才允许一次主动GET。已观察但403/429、账号不符、未登录、非JSON、响应体不可读、加载失败或来源冲突均停止，不以主动GET重新尝试。没有跨轮身份缓存。来源白名单只含账号双ID、run、当前作者身份、tab编号、方法/端点/HTTP状态及时间，raw JSON、headers、URL/query、Cookie、签名不保存。

账号证明交给后端重新核对run、原生双ID、首位作者、导航/观察时间及请求计数；生产run在取得证明前拒绝作者结果入库。历史run与capture版本不改写。

Xi Xu决策时未观察到self，所以补一次；最终self2表示网页又有一次self请求，晚到仍可能重复。观察范围只是本轮attach标签的Network.requestWillBeSent，含缓存、重定向和网页原生流量，不是全部浏览器流量或真正网络传输次数。其他页面事件数量差异不归因于这项优化，也不报告总请求下降百分比或全库速度。

## 实测后的顺序收敛

为减少过早补请求，最终代码将本来必读的首位前端计数放在账号复用决策前，让原生账号响应在这段必要处理期间完成；计数只读一次、先留内存，不增加专门等待计时器，未核验前不入库。该“读计数期间晚到self”分支通过离线测试。本轮两次实测在该顺序调整前，调整后没有追加第三次采集，不能宣称Xi Xu已经改为主动GET0。更晚才发出的self仍可能造成重复。
