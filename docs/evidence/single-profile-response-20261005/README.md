## 实测口径

使用用户已登记的Chrome profile，在后台临时页执行一次正常主页导航。导航前禁止网页JavaScript执行，并通过Fetch拦截只允许目标主页Document GET一次；所有后续资源/接口/其他Document请求拒绝，不跟随重定向。没有/self登录核验GET，没有作品列表GET，没有运行APP采集或写资料库。

实际HTTP200、text/html、858803字节，非磁盘缓存/非service worker响应。目标Document允许1次，其他资源请求在发出前阻止22次。拿到HTML后只在本地用不执行脚本、不加载资源的解析器检查DOM、JSON块、JavaScript字面量及流式JSON记录，未执行网页内嵌脚本。

此前曾另发一次独立、不带浏览器会话的GET，得到纯脚本页；用户明确登录会话后，这一结果被排除，不用于下述结论。整个调查有这两个独立试验，不能把两次调查操作合写成总共1GET；这里“1次”指有效浏览器会话试验的单次主页HTTP响应。
