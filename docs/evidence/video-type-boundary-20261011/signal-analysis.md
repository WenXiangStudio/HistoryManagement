# 三条视频的无模型信号分析（2026-10-11）

用户进一步授权无需模型的技术分析，要求汇报供用户裁决；技术检查无法确定类型时停止。本轮复用此前APP取得并保存的三条原片，执行独立离线脚本，不改APP产品流程，不下载，不播放或向Codex展示音频、图像、标题和发布文案。

**结论：三条解码音频均存在非零信号，抽样画面均存在显著像素变化；前两条包含明显低音量间隔，第三条在指定阈值下信号较连续。以上不足以判定口播/音乐、有无文字或信息由音频还是画面主导，三条内容类型均保持未确定，已停止进一步识别。**

## 方法与固定规则

仅使用Python标准库、NumPy数值运算和项目已有FFmpeg/FFprobe。脚本不使用网络库、不加载模型、不运行ASR/VAD/OCR，也不执行图像或音频语义识别。规则在读取本轮数值结果前固定；这些阈值是探索用规则，未经分类准确率验证。

- 音频：解码第一音轨，保留双声道、重采样16kHz，以20ms窗口计算所有声道样本的均方根能量。先平方再合并声道，避免左右声道相消导致假静音。统计低于−50/−40/−30dBFS的解码时长比例，单列持续至少0.3秒的低能量区间。−40dBFS约对应数字满幅1%的RMS振幅；这不是环境声压级或人耳可听阈值。
- 画面：沿时间轴每秒取2帧，等比例缩到宽160像素，转灰度后计算相邻帧的绝对像素差。帧只在程序内存中作数值计算，未导出为图片供Codex观看。
- “大幅变化”定义：相邻帧平均灰度差至少达到255灰度范围的8%，且至少25%的像素变化达到25级。报告中的百分比是满足此规则的相邻帧对比例，不是画面信息量、镜头切换次数或模型置信度。
- “近乎不变”定义：相邻帧平均灰度差不超过范围的1%，且变化至少25级的像素占比不超过1%。未达到此阈值不意味着一定存在语义变化。
