## 行为

- `DEBUGGER_NOT_ATTACHED`、`TARGET_NAVIGATED_OR_CLOSED`、`EXECUTION_CONTEXT_UNAVAILABLE`在本轮初始账号已经核验成功之后允许自动恢复。每位博主共享最多2次恢复预算，不因不同命令重置；第三次断开停止并明确提示。初始账号尚未核验时的故障继续停任务，不能凭未核验页面允许入库。
- 恢复前用独立扩展API检查原标签仍存在、未discard、当前URL与pendingUrl仍是该博主主页、没有可见验证码/登录失效或已观察的访问拒绝；用户手动取消调试连接不自动重新附加。页面变更、标签关闭、其他调试器占用等继续停。
- 每次恢复随机等待5～10秒，等待只轮询本机APP并响应暂停/取消，之后重新检查页面、必要时附加原标签并启用读取，再发一次登录身份核验GET。原owner UID/secUID必须都匹配。恢复账号核验请求单独计数，不冒充只核验1次。
- 不重新打开主页、不阻止页面特殊协议导航、不修改平台脚本/验证码或浏览器安全策略；原博主间5～10秒、批间3～5分钟继续执行。
- 扩展保存已确认的原生页和已投影页。显式列表GET在本页留下以run/author/cursor/readToken绑定的小投影回执；若连接在进行中GET时断开，恢复后先取该原文档的已完成/正在完成结果，**不会对同游标再发第二次GET**。如果文档已替换或结果不能确认，提示`ACTIVITY_RECOVERY_REQUEST_UNCERTAIN`并停止，不以盲重试掩盖问题。该缓存随临时页面关闭释放。
- 恢复只能授权重新读取，原账号、作者/主页归属、来源时间、分页连续性、公开状态、去重和60条采集校验保持。HTTP401/403/429、验证码、登录失效/账号不符、明确非连接错误不进入恢复流程。
- 主进程在独立表`creator_activity_recoveries`保留每次尝试、原因、等待/重连/成功/失败、时间与已保存页数；校验本轮目标、次数顺序、时间与阶段，已结束记录不得覆盖。任务中心和资料库刷新进度显示恢复等待/核验状态以及成功/尝试次数，暂停和恢复不隐藏历史失败。
