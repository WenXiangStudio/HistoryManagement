# 指定视频：单云端模型真实试验

2026-10-11，按照用户指令测试 https://v.douyin.com/s5upJSy-QXI/ 。**当前保存的 `gpt-6.1-sol` / Responses 服务可以读取图片并根据抽样画面生成受限摘要，但音频输入被拒绝，所测试的直接视频传输也被拒绝；“同一个云端模型完成转写、画面理解和摘要”的完整目标未通过。** 结论限定于当前服务、模型配置、协议和实测格式，不等于证明该名称模型在所有服务或协议上都不支持音频。

## 样本与输入

- 作者：盐选财经；作品 ID：`7691353360976416034`。
- 发布描述：十年期美债收益率破5% 股牛债熊 全球其他资产如何定价#美联储 #美债 #股市 #a股 #假期。
- 原片实际时长：478.725011 秒（约 7 分 59 秒）；1920×1080 H.264，AAC 双声道，240,456,200 字节。
- 原片 SHA-256：`a647d9fe3a878921391460230b6e8a52fcc4d5198ae67942de8f8090fc41d044`。
- 先解析用户短链接，并找到已有作者主页采集中的同作品身份；经现有关注连接器取得原生作品列表及当前登录账号证明，重新核对作品、作者、账号后下载原片。分享页未返回媒体，未将短链接直接当作已读取视频。
- 用 FFmpeg 提取前 12 秒音轨、前 8 秒视频，以及约 0.5、15、30、60、90、120、150、180、210、240、270、300、330、360、390、420、450、477 秒的 18 张图片。
- 实际文件复核：前12秒截取窗口导出的 WAV 为 11.844 秒 PCM；短视频容器为 8.008572 秒，其中视频轨 8.000 秒，音轨从 0.137007 秒开始、长 7.871565 秒。以上窗口标注不等于素材每一毫秒都存在音频；原片副本哈希与经归属校验下载的媒体一致。
- 18 张图逐张提供帧号与抽帧时点；时点仅表示截图位置，不是逐词或片段转写时间戳，也不表示连续覆盖。所有主图均为 1280×720 JPEG。
- 没有运行 Whisper、PaddleOCR 或另一套语义模型；未向云端提供旧转写、旧 OCR、作品标题或旧摘要。控制音频由 Windows 系统语音合成生成，专用于接口探测，不用于作品内容提取。

## 8 次请求的实际结果

全程只读取 APP 已保存的同一配置，使用同一个模型和 `/responses` 路线，不打印密钥，不切换协议，不另配视觉服务。任务合同放在 developer 输入，素材放在 user 输入，使用 `store:false`、`stream:true`；成功以 `response.completed` 为依据。

| 请求 | 实际输入 | 返回与结论 | 请求耗时 |
|---|---|---|---:|
| 图片控制 | 带未知校验文字和三种图形的 PNG | HTTP 200；准确读出 `CONTROL Q7M4 / 3826`、红方形、蓝圆形、绿三角形 | 6.700 秒 |
| 音频控制 | `input_audio` + WAV | HTTP 400：`Audio input is not available.` | 1.697 秒 |
| 音频文件控制 | `input_file` + `audio/wav` | HTTP 400：不支持该 MIME 类型 | 2.040 秒 |
| 视频文件控制 | `input_file` + `video/mp4` | HTTP 400：不支持该 MIME 类型 | 1.505 秒 |
| 真实音轨 | 原片前 12 秒，`input_audio` + WAV | HTTP 400：`Audio input is not available.`；无转写 | 1.994 秒 |
| 真实短视频 | 原片前 8 秒，`input_video` | HTTP 400：该类型不在允许枚举中 | 0.347 秒 |
| 真实画面 | 18 张图片 + 时点 | HTTP 200；返回逐帧字幕、画面观察、概览、7 条要点、主题及缺口 | 100.176 秒 |
| 字幕局部复核 | 第 11 帧字幕裁剪放大，不提供预期答案 | HTTP 200；正确读为“好再说下一个问题币值” | 13.956 秒 |

`input_video` 是一次兼容性探测，不据此宣称它是当前官方 Responses 标准字段；错误同时显示服务认识 `input_audio` 类型，但明确禁用音频输入。未探测服务商未提供说明的其他端点，也没有用格式穷举掩盖已知失败。官方音频与 Responses 页面本次访问均返回 HTTP 403，能力结论来自实际服务响应。

成功请求返回模型标识均为 `gpt-6.1-sol`。服务返回的成功请求用量合计 34,291 输入 token、4,706 输出 token；失败请求未返回用量，不能当作费用为零，也未依据单价估算费用。图片主请求自身为 25,074 输入、4,492 输出 token。

## 提取质量与实际可交付内容

完整保留[模型原始结构化结果](sampled-frames-model-output.json)和[输入哈希、响应错误、耗时及逐帧核对记录](verification.json)。结构与引用检查通过：18 张图片均有对应帧号和时点、要点引用均指向已提供帧、模型明确 `audio_received:false` 与 `speech_transcription.status:unavailable`。

代理逐帧查看实际输入图并核对 18 条前景字幕，初次有 17 条相符；**04:30 的“币值”被读成“市值”**。错误进一步传播到第 3 条要点：把该帧与 04:00 的“持有市值”归成同一话题。随后对字幕作普通图片裁剪放大，用同一模型无答案提示复核，得到正确的“币值”。原始错误结果继续保留，第 3 条原要点不作为已验证结论。背景书名未作为逐字验收对象。

这只是代理对实际图像的语义核对，不是独立人工基准，更不是音轨标准答案；不将 17/18 换算成模型 OCR 准确率。单个口播样本也不能证明图表、屏幕操作、才艺或其他长视频的质量。

## 后续判断

当前配置的能力边界已足够明确，不继续扩大样本或上传整段原片。若坚持一个模型完成全套处理，下一步需要有明确音频输入能力的服务/模型接入证据；不能靠多抽几张图解决听不到音频的问题。如果继续使用现有模型，它可承担画面读取与有材料约束的摘要，但另加 ASR 就应如实称为混合路线。尚未把试验脚本接成日常产品流程，也未改变本地路线、P2/P6/P7 或旧 R8 能力门。
