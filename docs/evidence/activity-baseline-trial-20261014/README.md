## 方法与实际采集

每位最近 180 天内最多 60 条有效作品，连续从最新游标读取，作者与主页归属、来源时间、公开状态、去重和普通作品排序独立校验。60 条上限、180 天边界、列表末尾分别记录停止原因。置顶按真实时间统计，旧置顶不导致跨过时间边界。保存整页证据，故原始记录可能超过60条。

最小真实验证刘润：4 页、81 条公开原始记录、60 条近期统计作品，复用1页原生响应、主动列表 GET 3次。验证阶段使用临时本机接收器，结果仅保存在验证文件；正式数据库在验证前备份，验证后恢复原本机连接并重新加载连接器。正式批量任务通过产品执行，不逐作者人工下指令。

批次为 28/28/28/28/28/27/27/27/27/27/27。共 10 次批间等待和 291 次同批博主等待，等待理论合计 54分15秒～98分30秒，此外还有实际浏览器读取、核验与入库耗时。等待时间算入全程。任务中心显示已成功位数、11批完成数、当前作者、倒计时、保存样本及最近结果，支持暂停、继续和重启后恢复剩余身份。

读取被限制、验证码、登录身份不一致、读取连接断开、排序/覆盖无法核实时停止全部后续任务并保存现场，不自动重试。随机间隔只限制请求密度，不是不会触发平台限制的保证。

近期平均相邻发布间隔参与原分档规则和人工优先级判断。历史累计间隔与原作品时间线保留并单独展示；少于2条近期作品时不给出虚构的0间隔。20/40/60前缀平均数保存用于后续比较，60建议值尚未经过全量准确率验收。
