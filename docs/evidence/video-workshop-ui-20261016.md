# 视频工坊规划与界面重做：APP 0.1.50

按用户最新安排，先更新视频工坊规划，再重做界面；第一步仅支持抖音视频。当前规范为[视频工坊：当前规划与界面设计](../architecture/video-workshop.md)，此前工坊规划不再作为新功能依据。

## 本次界面

- 主导航改为“视频工坊”，默认进入“新建处理”，不要求先绑定资料账号、选择博主或标记兴趣。
- 第一步提供抖音视频链接输入区，可输入完整作品地址、粘贴分享短链接或分享文本，本地提取并规范化单条地址。明确拒绝其他平台、伪装域名、主页、直播、合集与多条链接。可清空输入，切换页签保留草稿。
- 第二步展示“深度处理”入口及默认模型：豆包极速版 `volc.bigasr.auc_turbo`、`Qwen/Qwen3.5-122B-A10B`。
- 第三步展示图文分析与总结报告的空状态及时间、画面、语音、画面文字、分析结构；没有样例图片、伪造时间或模拟完成结果。
- 展示视频 `E:\VideoDownload`、音频 `E:\AudioDownload` 保存路径。
- 本轮为界面预览，清楚标示下载、分类和深度处理后续接入；“处理”“深度处理”保持禁用，不调用旧接口冒充新流程。
- 原感兴趣作品和截图移入“历史资料”查看入口，账号归属、焦点和迟到请求隔离保留。视频信息页保存兴趣后留在原页，点击“查看历史资料”才进入对应作品；历史资料不作为新流程任务或时间对齐报告。
