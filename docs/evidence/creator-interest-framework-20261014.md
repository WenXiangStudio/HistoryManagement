# 兴趣度分组框架：APP 0.1.45

本次先搭建资料库的第二套分组框架，不对现有博主进行兴趣度归类。

- “活跃度分组”和“兴趣度分组”是同级视图，可互相切换。
- 活跃度视图继续显示：高频、中频、低频、极低频；原异常入口和刷新逻辑保持不变。
- 兴趣度视图预留：高、中、弱三个分区，当前人数为0，卡片不会被临时规则挪动。
- 兴趣度视图显示“刷新兴趣度”占位按钮，但按钮禁用并标注“待定义”，不会启动刷新、采集、模型任务或改变任何资料。
- 兴趣度划分规则暂未确定，避免用星标、批注、已有视频或其他信号替用户做不可逆推断。

验证：77组645项测试、TypeScript、构建、Windows打包和 packaged-renderer 冒烟通过。新增回归确认视图切换、三个空分区、禁用占位刷新按钮、切回活跃度后原四档刷新按钮恢复，且没有触发刷新任务。

日常 APP 已更新为 0.1.45.0，正常启动、online/ready。更新前后两份正式数据库逐表散列一致，302位博主、95条视频、5条兴趣作品、正文报告、星标批注、权重、凭据和账号设置保留。
