# 设置中的云端模型连通测试：APP 0.1.49

用户要求所有云端模型配置区域都提供“连通测试”，配置保存后可直接确认接口是否可用。

## 使用与结果

- 硅基流动每张模型卡片独立提供“连通测试”，包括后续用户自行新增的模型；无须先切换成当前方案。
- 通用云端兼容 API 的文本与视觉区域各有按钮。文本遵循已选 Chat Completions 或 Responses，视觉遵循既有 Chat Completions 接入方式。
- 豆包语音凭据下增加独立按钮，与原有指定视频的单条转写入口分开。
- 点击后显示“测试中…”，结束显示连接成功或失败、具体原因、测试耗时及上次测试时间。未填写或未保存时显示对应提示；同一目标重复点击不会重复请求。
- 编辑、切换方案或保存凭据后旧结果失效，迟到结果不挂到新模型；轮询不会清除同一配置的结果，也不会自动发起测试。

## 实际请求及归属

文本测试只发一条最小 user 消息，视觉测试发程序生成的 32 × 32 PNG，豆包使用内存生成的一秒 PCM WAV 静音。测试使用指定已保存模型和密钥，受配置身份与 revision 校验约束，不修改当前方案，不写正文、摘要、语音试验记录或业务结果。

Chat Completions、Responses 同时兼容 JSON 与同协议 SSE，只在有有效文字时判定模型已响应；测试输出达到 token 限制但有可见文字时显示成功并说明截断。HTTP 401、403、404、429、服务错误、空输出、协议不符和网络超时显示失败原因。单次模型测试最长 45 秒、响应最多 256 KiB；不自动重试或切换协议。

豆包支持 API Key 和 APP ID＋Access Token，校验 HTTP 与业务码。官方极速版文档将 `20000003` 定义为“静音音频”，该返回显示鉴权及服务调用已通过，明确说明没有验证真实语音转写内容；`20000000` 另检查识别结构与一秒音频时长。30 秒总超时、64 KiB 响应限制，配置与历史转写保留。测试可能产生少量云端用量。
