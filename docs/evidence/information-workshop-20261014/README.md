# 信息工坊导航与兴趣作品收录：APP 0.1.35

用户要求新增“信息工坊”导航页，“视频信息”中的作品点击感兴趣后进入该页，随后明确纠正：信息工坊不要继承视频信息的待分类、处理中、待人工审核和已完成状态。本次以此纠正为实现范围。

信息工坊是独立导航页，展示当前资料账号标记感兴趣的作品。点击感兴趣后先通过已有主进程接口保存选择，成功才切换到工坊并定位刚选择的作品；保存失败、不感兴趣或清除标记不触发跳转。页面按现有账号和作品身份读取，保留视频信息中的原作品，不复制、搬走或删除档案。

工坊展示作品标题、作者、完整发布描述、发布时间、时长、已有截图及互动数字，可搜索作品、博主与发布描述，查看原视频或返回视频信息。前端仅投影基础字段和截图引用，不带入分类标签、处理阶段、审核结果、正文或研究报告，不创建对应工坊状态。无截图时显示“暂无已保存截图”；没有分类、处理结果或正文也不影响感兴趣作品进入工坊。现有兴趣保存及后台处理规则未在本轮改动，工坊本身不另发采集、分类或模型任务。

已保存的感兴趣作品自动显示；取消兴趣后退出工坊展示，原作品与资料保留；重新标记沿用同一作品，无重复卡片；重启保留兴趣选择。资料账号切换及迟到响应不会将另一账号作品混入工坊。侧栏徽标统计当前账号的感兴趣作品数量。

验证：73组605项应用测试、TypeScript、项目边界、构建、打包renderer冒烟通过。新测试覆盖即时收录不依赖阶段、无状态/标签/正文泄露、截图读取、成功保存才导航、保存拒绝不跳转、取消/恢复兴趣、账号切换迟到响应与错误账号响应。已有兴趣处理测试保留通过。

实际日常数据库副本验证显示5条既有感兴趣作品、8张详情截图可读，宽屏与1120×720无横向溢出、渲染错误0、继承状态节点0。在隔离副本另加1条明确合成的无分类作品，通过实际兴趣IPC按钮完成保存与跳转定位，重启确认仍在工坊；再点击不感兴趣，仅退出工坊，原作品仍在库。合成作品阶段记录0，无外部处理；正式用户兴趣选择未改。

日常APP已更新至0.1.35，原快捷方式与资料目录保持，正常启动无调试端口。Windows可访问性验证日常信息工坊5条作品、截图标题可见、无继承状态。连接online/ready，停留信息工坊，视频总数95。

保留审计：两库所有原行身份和已完成结果、既有兴趣选择、博主星标批注、视频95条、账号配置、runtime及全部凭据保留；完整性ok、外键错误0。重启沿用既有VideoContentStore.interrupt规则，将8条原本running、结果为null的历史阶段占位记录标为interrupted，并写“应用退出中断”，其他字段与全部其他表不变。这是既有启动规则，不能声称两库每个原始字段完全未变，也没有将这些状态显示在工坊。
