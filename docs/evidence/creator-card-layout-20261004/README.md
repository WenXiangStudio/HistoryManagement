# 本周更新数与卡片简介布局 · 2026-10-04

用户要求每张卡片同时显示本周更新数和具体最近发布时间，周期独立一行；简介预览最多三行，超出可展开，展开内容不透明且不遮挡其他内容。本轮已更新现用桌面APP，不启动新的采集，不改关注扩展0.6.2。

## 更新数

格式为“本周更新 x 条 · 最近更新 YYYY-MM-DD HH:mm”，下一行为“本周记录周期：09.28～10.04”。本周无公开作品显示更新0条、最近更新“—”；尚未检查或覆盖不完整时数量待检查/待确认，不把已见部分数量伪装成确定全周数量。

计数使用已有白名单源页，按原生aweme_id去重，核对目标作者双ID与公开可见性；只纳入北京时间固定日历周内、且已在该次检查时发布的作品。周内置顶也计数，重复置顶不重复累计；外作者、周外和检查时刻后的作品不计。覆盖完整才保存确定数量。新结果写snapshot字段weeklyUpdateCount，历史快照在读取时根据原capture补算，历史数据库行不重写。

180位历史来源均回验成功，100位有更新、80位为0，按各自已保存检查时点共329条公开作品。这是保存快照的周内条数，不代表本轮刷新了全部博主。例：爱学习的乔同学2条；圈圈包子4条；林文冠AI5条。

## 简介布局

移除简介固定36px高度。默认保留最多三行、超出显示省略和“展开简介”，完整简介原文保留。展开后为正常文档流中的白色不透明气泡，有边框、阴影及小箭头，主页链接和下方数据随气泡下移，收起可恢复。过长完整简介在气泡内滚动，键盘可操作展开按钮，aria-expanded与aria-controls对应。主页链接继续单行省略并保留完整href/title及点击处理；“已分析”继续显示“—”。

真实APP180张卡片在正常和1120px窗口下简介均不超过三行，简介与主页链接重叠0，横向溢出0，全部主页地址与原资料一致。13张长简介可展开；截图指定圈圈包子和林文冠AI核对通过。圈圈包子气泡完整原文一致、白色背景alpha=1、opacity=1，展开后链接没有重叠。已查看展开、折叠与较窄窗口截图。

原8张数据库表哈希全部一致：180位、12次关注run、370条历史快照/尝试、8次动态run及账号元数据不变，integrity=ok、外键违规0。没有新增采集run。240项应用测试、周内去重/置顶/时间边界/未知数量与历史只读补算测试、TypeScript、build、package、真实界面和打包renderer检查通过。现用原包已更新并从桌面快捷方式重开。
