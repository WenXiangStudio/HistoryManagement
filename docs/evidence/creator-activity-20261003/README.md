## 字段来源与真实修正

作品总数为公开视频和图文合计，来自同一作者资料响应 `user.aweme_count`；本周动态来自作品列表的原生ID、作者双ID、发布时间、置顶和公开可见性字段。两项在同轮读取，以同一事务保存快照和检查时间。失败保留上次可信值，未知不显示0。

最小真实读取先证明IT咖啡馆总数224和作品列表可用，并观察到三条旧置顶作品。随后发现无公开客户端版本参数的接口只统计视频：Xi Xu返回3，但真实主页显示16。采用真实网页观察到的公开客户端参数后，总数为16，列表为3视频+13图文，均公开可见，与主页一致。只保存白名单业务字段，不保存Cookie、签名或设备标识。首次旧口径数据保留为诊断，不进入最终显示。见 [可行性与计数修正](feasibility.json)。

作者列表还会混入另一作者作品。仅双ID明确属于另一作者时排除并记录；身份冲突或缺失停止该作者检查。最终27条外作者作品被排除。旧置顶不参与非置顶排序推断；只有连续分页跨越周起点或列表自然结束，才标本周覆盖完成。空列表还要求独立总数0；空页仍有下一页不宣称暂无更新。
