# 视频信息独立导航页验收（2026-10-10）

APP **0.1.15**，关注连接器仍为 **0.8.5**。用户要求将视频信息弹窗改为与博主资料库、博主数据库平级的导航页，并设计页面排版。本轮只改本地查询与展示，没有运行平台采集、媒体下载或外部分析。

## 页面与交互

- 左侧新增“视频信息”导航，集中查看当前账号所有已保存视频；原博主卡片跳转同页并按稳定博主身份筛选。
- 顶部概览：已保存视频数、博主数、最近采集时间、采集对象和原有单视频采集按钮。
- 中间工具栏：搜索标题/完整发布文案/博主/作品 ID；按博主筛选；按发布时间、首次收录时间或点赞排序。
- 主体左侧为视频列表，右侧为详情；两侧独立滚动。正文完整保留，列表标题/摘要截断仅影响列表预览。
- 详情包含作者、发布时刻、时长、精确互动数、完整文案、首次收录/数据更新时间、作品 ID；提供复制文案、打开原视频、返回博主资料。
- 导航切换保留筛选/选择，隐藏页面暂停效果和轮询；账号切换重新挂载并拒绝不匹配的响应。无视频/无搜索结果均有空状态。

## 现场验证

使用用户已有的 **2 位博主 / 2 条视频**：“口罩哥研报60秒”和“爱学习的乔同学”。读取的长文案与本地保存全文逐字一致。通过真实 APP 导航验证：

1. 平级导航显示全部记录，未出现旧模态弹窗。
2. 搜索完整描述可筛选到正确作品。
3. 视频详情 → 博主资料 → 卡片视频信息往返正确，返回时筛选为该博主；“查看全部”恢复全库。
4. 常规窗口与 **1120 × 720** 布局无横向溢出，窄窗口可滚动至文案末尾、时间和原视频按钮。
5. 浏览前后采集 run ID 不变，本轮没有新增平台采集。
