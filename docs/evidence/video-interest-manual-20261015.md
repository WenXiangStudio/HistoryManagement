# 兴趣标记与视频处理分开：APP 0.1.47

用户要求视频信息页标记“感兴趣”后停止自动转写、识别等后续处理。

## 实现行为

- “感兴趣”只保存判断并收录到信息工坊，保留原先保存成功后进入工坊的导航；不创建处理任务，不调用转写、画面文字识别或研究模型。保存兴趣不再受其他采集或处理任务空闲限制。
- 移除原来兴趣保存、分类完成、人工更正分类三处自动入队入口。已标记作品稍后完成分类，也不会自行处理；重启同样不会因已有兴趣标记而续跑。
- 视频详情新增明确的“开始处理”按钮，有已有正文时显示“继续处理”。主进程`startProcessing`及`video-workflow:start`在任何入队前校验当前账号、全部所选作品归属、感兴趣状态和有效分类；口播与图文按原路线处理，其他类别先提示审核、分类或人工观看。
- 收件箱“继续生成研究报告”改为调用显式处理接口，复用已有正文；再次标记“感兴趣”不再承担失败重试行为。
- 已有分类、截图、正文、报告及历史记录保留。取消兴趣仍能中断当前作品后续处理，避免保存已取消的迟到结果。
- 基础采集后的本地分类仍按既有产品流程执行。用户明确选择继续已有任务，或点击“保存校正文案并更新研究报告”，属于显式处理操作，行为保留。报告模型、128000输出额度、15分钟超时和正文／引文校验保持。

实现涉及：`src/main/videoWorkflowService.ts`、`src/main/index.ts`、`src/preload/index.ts`、`src/renderer/src/VideoInformationPage.tsx`、`src/renderer/src/VideoClassificationPanel.tsx`、`src/renderer/src/MaterialInbox.tsx`。
