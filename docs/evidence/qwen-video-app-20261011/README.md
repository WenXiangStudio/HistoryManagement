## 内容核对及尚未通过的质量项

代理查看实际18张输入图，前景字幕逐条与模型输出一致，包括首帧“当美国以5%的利率借钱”、片尾“用这么高的利率去借钱”。画面均为书架前口播，已抽样帧未出现图表；不能据抽样推断全片绝无其他画面。这是代理视觉核对，不是独立人工基准或模型准确率统计。

转写包含首段美债收益率、中段日本/资本流动及末段股债配置内容。第四至第五分钟准确出现“币值”，未复现上一模型静态帧将“币值”读成“市值”的同一问题；但本次语音与上一轮静态图的输入不同，不把它作为两模型的公平准确率比较。

需要保留的缺口：

1. **摘要比较基准错误。** 第1条写“其他国家若要吸引资金就必须提供高于5%的风险溢价”；保存的转写区分的是超过5%的总收益基准与额外风险补偿。摘要把5%门槛直接套在风险溢价上，改变了口径。这是摘要相对其输入转写的可确认偏差，尚未经逐字核听。
2. **引用未覆盖整条观点。** 第6条包含“美股扮演抽水机效应”，但引用的是speech-cloud-7/8，该表述实际在speech-cloud-6。引用ID存在性校验通过不代表语义引用覆盖充分。
3. **分段断句。** 60秒硬切会把一句话甚至一个词拆在相邻段；如第3段末尾“政”和第4段开头“政府”衔接不自然。没有独立逐字人工核听，不能宣称完整准确转写。
4. **音画措辞差异。** 片尾图像为“用这么高的利率去借钱”，模型音频稿为“有这么高的利率去借钱”。这属于待核听差异，未自动用字幕覆盖音频结果。专名、年份及数字同样待用户检验。
5. **静态画面边界。** 本次主流程理解的是18张抽样帧，没有连续动作分析；本轮口播样本不能证明第二种视频类型也可用。模型生成的“全片没有任何图表”等绝对化说法不作为验证结论。
