## 使用与继续开发

日常由 APP 连续完成浏览器读取、校验、去重、入库和展示。用户可以选择单作者、勾选多作者或全部作者；首次失败停止后续作者，保留故障网页并捕获日志。没有后台定时采集。

公开作品总数取主页“作品”计数；本周统计来自可信作品列表，时间范围为北京时间周一至周日。最近发布时间只覆盖本周；本周零条时为 null。未知与失败保持待检查/待确认，不写成零。

失败证据在扩展本地缓存和 APP SQLite 分别尝试保存，先冻结后补页面/截图。两处均失败时无法保证落盘，网页仍保留。明石历史具体根因未知；当前小样本结果不代表长期成功率已证明。

正式作品详情/评论采集能力门仍关闭。关注清单及资料刷新验收不替代 R8 门禁；开机、其他真实账号/Chrome 配置以及更长时间使用的边界需按对应历史证据判断。

历史交接与方案阶段集中在 [按月历史索引](archive/README.md)。旧文件里的版本、资料数量、构建路径和“等待下一窗口”等描述属于当时记录，不是当前操作指令。
