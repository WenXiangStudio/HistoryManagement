## 当前能力

- 账号隔离的累计博主目录，主页身份去重，星标、批注和历史证据保留。
- 高频／中频／低频／极低频四档，平均间隔边界7／14／30天。高频须最近成功核验时七天内有发布；超过30天未发布优先极低频；原高频超过7天、未超过30天未更新归中频。
- 分组与昵称颜色固定于成功核验结果，不因时钟前进自动改判。七天无更新为红色昵称、`#FF8247`日期，手动权重紫色优先。手动目标固定，关闭恢复自动分类。
- 作品数增加≥10或记录断层进入独立异常组；有效基线隔离，逐作者补齐通过才解除。常规批量更新跳过待处理异常。
- 数据库自定义列、筛选、间隔图表、飞书单条／全库／自动同步；数据库虚拟列表及资料库切换优化保留。
- 目标页内容已可读时继续稳定性核验；浏览器读取断开及时报告，停止后续任务并保存现场。
