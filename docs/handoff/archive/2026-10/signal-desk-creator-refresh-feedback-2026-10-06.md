日常版本仍为应用 **0.1.11**、关注连接器 **0.7.9**，原桌面快捷方式对应的包已更新并重新打开。本次仅修改 renderer，打包前后 main 与 preload 内容 SHA256 一致。

## 展示行为

- 当前周已确认 `weeklyStatus=empty` 且 `weeklyUpdateCount=0` 的卡片明确显示 **近期暂无更新**，继续显示记录周期与检查时间。待检查、部分结果与跨周失效数据不会被写成暂无更新。
- 用户点击单卡刷新后，启动提示仍为“正在更新作品总数与本周动态”；同一 run 完成且全部成功时，显示“博主名称刷新成功”。本周无更新时追加“近期暂无更新”。卡片移动分区后仍保留该次 **刷新成功** 标记，标记绑定作者 ID 与本次尝试时间。
- 全部或所选博主刷新完成时显示成功人数。结果不完整、被阻止或取消时显示对应结果，不提示刷新成功。完成状态先到而该作者数据仍是旧尝试时，等待本次卡片数据后再提示。
- 同一 run 仅通知一次，打开 APP 时不会把历史完成记录重新提示为本次成功。再次刷新会清除旧的单卡成功标记。
